    \begin{column}{.45\colwidth}
    \textbf{End goal: create a general exploration model.}
    \begin{itemize}
        \item Navigate in a real 3D open world.
        \item No fine-tuning or external help required.
        \item Understand the (visual) context.
    \end{itemize}
    \end{column}
    \begin{column}{.45\colwidth}
    \textbf{How to evaluate such a method?}
    \begin{itemize}
        \item Simulation based evaluation.
        \item Vision-language reasoning-based challenges.
        \item Tasks requiring context awareness.
    \end{itemize}

\begin{columns}[t,totalwidth=\colwidth]

\begin{column}{.30\colwidth}
\begin{itemize}
\item The object is within line of sight from the starting position (though it may be far away).
\item The object is described by text (e.g. ``a red sports car'').
\end{itemize}
\end{column}

\begin{column}{.30\colwidth}
\begin{itemize}
\item The target object is an easy-to-spot anomaly (e.g. a flying saucer/UFO).
\item The object description is \textit{not} given to the model; the task is to look for an anomaly.
\end{itemize}
\end{column}

\begin{column}{.30\colwidth}
\begin{itemize}
\item The object can be hidden behind obstacles.
\item Larger search area.
\item The object is described by text and an image of a similar object is provided.
\end{itemize}
\end{column}
\end{columns}
